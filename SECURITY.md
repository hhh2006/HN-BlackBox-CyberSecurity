# Security Policy

HN BlackBox is a cybersecurity learning and defensive engineering project.

## Scope

Use the tools only against systems, networks, applications, and data that you own or are explicitly authorized to test.

The project is not intended to provide unauthorized access, credential theft, persistence, destructive behavior, or evasion tooling.

## Reporting a vulnerability

If you discover a security issue in HN BlackBox itself, please use GitHub's private security reporting features when available. For project security communication, you can also contact **alnasryhany185@gmail.com**. Avoid publishing sensitive details in a public issue before a fix can be prepared.

## Secrets

Never commit API keys, passwords, private keys, session tokens, or other credentials.

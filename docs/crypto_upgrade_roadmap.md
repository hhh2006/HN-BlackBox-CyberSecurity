## Status taxonomy

- **IMPLEMENTED** — exercised by the current automated test suite.
- **PARTIALLY IMPLEMENTED** — present but only part of the intended scope is wired.
- **MOCK** — intentionally simulated/presentation-only; must never be described as real telemetry.
- **NOT CONNECTED** — UI exists but is not connected to an engine/data source.
- **NOT SUPPORTED** — intentionally outside the current release.
- **CONFIGURATION REQUIRED** — requires local environment setup.

## Modern Crypto Command Center — v1.8
**Status: IMPLEMENTED**

The Modern Security page now provides dedicated workspaces for DES, AES-256, RSA, and hashing with real local execution, algorithm-specific explanations, visual execution paths, and regression-test hooks.
